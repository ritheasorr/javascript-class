# Movie Detail Page Project

## Overview
This project is a simple web application that displays a list of movies in card format. When a user clicks on a movie card, they are taken to a detailed page that shows more information about the selected movie, including its poster and description.

## Project Structure
```
movie-detail-page
├── src
│   ├── index.html          # Main entry point of the application
│   ├── movie-detail.html   # Displays detailed information of a selected movie
│   ├── css
│   │   └── styles.css      # Styles for the application
│   ├── js
│   │   ├── app.js          # Initializes the application and handles navigation
│   │   ├── movieCard.js     # Creates movie card elements dynamically
│   │   └── movieDetail.js   # Retrieves and displays movie details
│   └── data
│       └── movies.js       # Contains movie data
└── README.md               # Documentation for the project
```

## Setup Instructions
1. Clone the repository to your local machine.
2. Open the project folder in your preferred code editor.
3. Open `src/index.html` in a web browser to view the application.

## Usage
- The main page (`index.html`) displays a grid of movie cards.
- Click on any movie card to navigate to the movie detail page (`movie-detail.html`), which shows the movie's poster and additional details.
